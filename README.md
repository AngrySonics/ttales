# Treasure Tails source code
Treasure Tails/Treasure Tales/Treasure Tales: starring Miles Prower prototype source code (from April 7, 1993, going off of the original modified file dates) mirror (The original is from [Hidden Palace](https://hiddenpalace.org/Assets/Treasure_Tails/Source_Code).) This also includes the source code for [GEMS 2.2](https://segaretro.org/GEMS) (the sound driver this prototype uses), but you're probably just here for the prototype.

A DOS machine/DOSBox/A virtual machine that can run MS-DOS must be used to compile this. MS-DOS is NOT needed for any of the .doc files, since Office 2024 is capable of opening ancient .doc files like the ones provided in the source code (programs like LibreOffice (or OpenOffice, but you're likely better off using LibreOffice) have not been tested, but if Office 2024 can open them, they should theoratically open them too). It could be possible to get this to compile using modern tools (such as AS), but I (or anybody else) have not tested this yet.
