# ttales
Treasure Tails/Treasure Tales prototype source code (from April 7, 1993, going off of the original modified file dates) mirror (The original is from [Hidden Palace](https://hiddenpalace.org/Assets/Treasure_Tails/Source_Code).)

A DOS machine/DOSBox/A virtual machine that can run MS-DOS must be used to compile this. It could be possible to get this to compile using modern tools (such as AS), but I (or anybody else) have not tested this yet.
